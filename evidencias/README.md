# Evidencia agregada

Los archivos CSV de este directorio conservan métricas de validación, métricas de prueba final, comparaciones de concentración comercial y los valores agregados utilizados para las figuras. Son resultados numéricos a nivel de criterio y corte; no incluyen filas individuales de clientes.

`controles_prueba_colab.md` resume la bitácora de prueba final y los controles registrados. La ejecución se efectuó en Google Colab con Python 3.13.18 y scikit-learn 1.6.1. Los hashes cotejados se describen en `../docs/trazabilidad_y_limitaciones.md`.

Los CSV agregados no permiten reconstruir predicciones o selecciones individuales. Los archivos cliente-corte y las predicciones por cliente permanecen como entradas externas bajo custodia de la autora.
